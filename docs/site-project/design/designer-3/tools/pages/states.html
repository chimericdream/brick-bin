The motif, in one screen

Where bricks go

  • Text size: 1×1 bullets, nav chips, the current “On this page” item. Always next to words.
  • Component: buttons, page heads, step numbers, parts box, callouts, next bricks, the current docs item, phone-menu links.
  • Architecture: the hero stack, one plate band, the CTA brick, the footer wall, the 404 wall. One per screen.

Where they never go

  • Behind running text, inside tables, code blocks or form fields.
  • Scattered, tilted, or as a pattern without a job.
  • With anything printed on a stud, in red and yellow, or as a minifigure.
