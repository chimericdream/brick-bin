Setup

From an empty machine to the first-visit screen. The recommended route uses Proxmox, Docker and Tailscale. There's a shorter one if you only want a look around.

Before you start

What you need

1×
A machine that runs Docker. A Proxmox VM or LXC container is the recommended home.
1×
A Tailscale account and an auth key, for the recommended install
~10 GB
Disk to start: several GB for the catalog, a few hundred MB for the database. Instruction PDFs grow to tens of GB over time.

A quick try-out

No Tailscale, no HTTPS, nothing permanent. Good for deciding whether Brick Bin is for you.

  1. Get the compose file

    Download the production compose file and the example environment file from the repository into an empty folder.

  2. Set a database password

    Copy .env.example to .env and set POSTGRES_PASSWORD and DATABASE_URL. Everything else can stay at its default for now.

  3. Start it

    Terminal
    docker compose -f compose.prod.yml up -d

    Then open http://<machine-address>:3000. Change the port with APP_PORT.

The recommended install

A Proxmox VM or LXC with Docker, reached over Tailscale. The stack has four parts:

  • The app, Brick Bin itself.
  • Postgres 17, its own database. Never updated automatically.
  • A Tailscale sidecar that serves HTTPS at https://brick-bin.<your-tailnet>.ts.net.
  • Watchtower, which checks for a new app image every five minutes.

  1. Make the home

    Create a VM or LXC container on Proxmox and install Docker in it. The hosting guide covers sizes.

  2. Fill in the environment file

    Four values matter on day one. The rest have sensible defaults, listed in Configuration.

    .env
    POSTGRES_PASSWORD=choose-something-long
DATABASE_URL=postgres://<user>:<password>@db:5432/<database>
TS_AUTHKEY=tskey-auth-…
COOKIE_SECURE=true

  3. Start the stack

    Run the same docker compose up -d command. The sidecar joins your tailnet and the app answers at its ts.net address within a minute or two.

Keep the .env file safe

Never commit it to a repository, and keep a copy with your backups. Without the database password, a backup is a very tidy box you can't open.

First visit

The first visit asks you to create the household and the admin account. Whoever does this is the admin, so it's worth being the grown-up in the room. Everyone else gets added from there.

Import the catalog

Brick Bin works without the LEGO catalog, but searching by set number needs it. The first import downloads about 6 GB of part images plus a data archive, and can run at most once every 48 hours. The import tutorial walks through it.

Catalog data comes from Rebrickable.
