Tutorials

Ten walk-throughs, in roughly the order a household needs them. Each one starts with what you need, so you find out before step three that you needed it.

Getting started

  • First run

    Create your household and the admin account on the first visit.

    4 steps

  • Import the LEGO catalog

    Paste Rebrickable's downloads page, press the button, and learn why it then rests for 48 hours.

  • Add your first set

Day to day

  • Track several copies and change build state

    Give each box its own place, owner and price, then move it from sealed to built with one tap.

    5 steps

  • Record missing pieces and work the shopping list

    Log the parts a copy is short of, then take the list to the shop or export it.

    7 steps

  • Attach instructions

    Upload a PDF, save a link, or have Brick Bin save a PDF from a web address.

The household

  • Set up a kid profile

    A read-only profile with no prices and no shopping list, and how to hide a set completely.
