Theme

Know what's in every box.

Brick Bin is a free, self-hosted web app for your household's building-brick sets: LEGO, Mould King, CaDA, COBI, BlueBrixx, Lumibricks and whatever arrives next.

It runs on your own server and keeps track of each box you own, where it lives, how built it is and which pieces have gone missing. Made for families and collectors who are happy running a small home server, and for anyone curious enough to try.

A set is the design. A copy is the box.

You might own five of one polybag: one sealed , one built on a shelf , and three in a tub, one of them four pieces short . Brick Bin keeps every box apart, each with its own build state, place, owner, price and value.

What it keeps track of

Sets, the boxes you own of each, and everything that goes missing from them. All of this is in version 1.

How self-hosting works

Four steps, from an empty machine to your first set. Most of the time goes on the catalog download, which is a fine excuse to go and build something.

  1. Give it a home

    A Proxmox VM or LXC container with Docker is the recommended home. Any machine that runs Docker will do for a try-out.

  2. Start the stack

    One compose file starts the app, its own Postgres 17, a Tailscale sidecar and Watchtower.

  3. Open it on your network

    Tailscale serves it over HTTPS at https://brick-bin.<your-tailnet>.ts.net. The first visit asks you to create the household and the admin account.

  4. Import the catalog

    An admin presses the button and Brick Bin loads the LEGO catalog from Rebrickable: about 6 GB of part images plus a data archive.

Updates look after themselves. Watchtower pulls a new app image every five minutes. Postgres is never updated automatically, because a database upgrade deserves a person in the room.

Only want a look? Run the production compose file without Tailscale and open port 3000. Read the hosting guide →

What you won't find here

An account with us

You create the only account, on your own server. There is no Brick Bin cloud to sign up to.

A subscription

Brick Bin is free and open source. Nothing to renew, and no paid tier further down the page.

Tracking

No analytics, nothing loaded from a CDN, no background downloads. This site doesn't track you either.

Not in version 1, either: loose-brick inventory, owned minifigures, a build log, loans, ratings, guest share links, price-guide integrations and currencies other than USD. Better to know now than after the catalog download.
