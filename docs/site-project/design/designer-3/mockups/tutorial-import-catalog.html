Import the LEGO catalog

Fill Brick Bin's catalog with LEGO sets and parts from Rebrickable, so you can find sets by number and pick missing pieces from a set's real inventory.

Goal and what you need

Goal: searching for a LEGO set by number or name finds it, and missing pieces come with pictures.

The catalog is data from Rebrickable. Brick Bin never fetches it on a schedule. It arrives when an admin asks for it, and at no other time.

What you need

1×
Admin account, from the first-run tutorial
1×
Computer with a browser. Copying a page's source is easier there than on a phone.
6 GB
Free disk for part images, plus room for the data archive
48 h
Since the last import, if there was one

Steps

  1. Open the catalog page

    Sign in as an admin and open Settings, then Catalog. On a new install it says nothing has been imported yet, which is true.

  2. Open Rebrickable's downloads page

    In a new tab, go to Rebrickable's downloads page. You don't need to sign in or click anything there.

  3. Copy the page's source

    View the page source with Ctrl + U (⌥ ⌘ U on a Mac), select everything, and copy it.

    Why the copy and paste?

    Until Rebrickable confirms that automated page reads are fine, Brick Bin won't read that page for you. For now, you are the fetch. An admin can switch this on later with REBRICKABLE_PAGE_FETCH.

  4. Paste it into Brick Bin

    Back on the Catalog page, paste into the box and press Check. Brick Bin reads the page and lists the files it will download, with their dates.

  5. Press Import

    The first import downloads a data archive and about 6 GB of part images. How long that takes is up to your connection, so this is a good moment to put the kettle on.

  6. Check that it worked

    Open Add a set and search for a set number you know. If it turns up with its picture, the catalog is in.

  7. Leave it alone for 48 hours

    An import can run at most once every 48 hours. If the Import button is disabled when you come back, that's why, and the page tells you when it's available again.

The 48-hour limit

The catalog is only as fresh as the last time an admin pressed the button. If a brand-new set is missing from search, run another import once the 48 hours are up. Until then, you can add it by hand.

Nothing updates by itself

Brick Bin makes no background downloads, so a catalog from last spring stays a catalog from last spring until someone imports again.

If something goes wrong

  • “No files found” after pasting. You probably copied the visible page rather than its source. Go back to step 3.
  • The import stops part-way. Check free disk space first. The part images need about 6 GB.
  • You restored from a backup and the pictures are gone. That's expected: catalog images aren't backed up. Run an import again. See Backups.

Catalog data comes from Rebrickable.
