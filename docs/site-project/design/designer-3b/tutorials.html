Ten tutorials, in the order you'll want them

Each one has a goal, a short list of what you need, and numbered steps with pictures. Start at the top if the server is new. Otherwise, go straight to the job in front of you.

Getting going

  • 1First runCreate your household and the admin account on the first visit.4 steps
  • 2Import the LEGO catalogLoad Rebrickable's catalog by pasting its downloads page, and learn why the button then rests for 48 hours.7 steps
  • 3Add your first setThree ways in: search the catalog, scan a barcode, or type in an off-brand set by hand.6 steps

Day to day

  • 4Track several copies and change build stateGive each box its own place, owner and price, then move it from sealed to built with one tap.5 steps
  • 5Record missing pieces and work the shopping listLog the parts a copy is short of, then take the list to the shop or export it.7 steps
  • 6Attach instructionsUpload a PDF, save a link, or have Brick Bin save a PDF from a web address.4 steps

The household

  • 7Set up a kid profileA read-only profile with no prices and no shopping list, and sets you can hide from it.5 steps
  • 8Run a wishlistPrivate "I bought this" marks, and "We got it" when the box arrives.6 steps

Bigger jobs

  • 9Import from CSVBring in a Rebrickable set list, a Brickset export or any spreadsheet.6 steps
  • 10Check collection valueTotals, paid against estimated value, and the values that have gone stale.4 steps

In these mockups only "Import the LEGO catalog" opens a full page. The other nine use the same template.
