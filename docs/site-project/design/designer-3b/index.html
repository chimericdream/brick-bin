Know what's in every box.

Brick Bin is a free, self-hosted web app for a household's building-brick sets: LEGO, Mould King, CaDA, COBI, BlueBrixx, Lumibricks and whatever arrives next.

It runs on your own server and remembers each box you own, where it lives, how built it is and which pieces have gone missing. It's for families and collectors who run a small home server, or are curious enough to start.

What it keeps track of

Sets, the boxes you own of each, and everything that goes missing from them. All of this is in version 1 today.

  • OpenedIn progressBuilt

    Build state

    Sealed, opened, in progress, built, disassembled or mixed. Each copy has a one-tap menu to move between them.

  • Plate 1 × 2, dark tan× 4

    Missing pieces

    Logged as real catalog parts: part, colour and quantity, with pictures. Pick from the set's own inventory or search the whole catalog.

  • Store tripBrickLink XMLCSV

    Shopping list

    Everything missing, grouped by part and colour. Use store-trip mode on your phone, or export to BrickLink wanted-list XML, Rebrickable CSV or plain CSV.

  • 48 hbetween imports, at least

    Catalog lookup

    Search LEGO sets using Rebrickable data you import yourself. Nothing is fetched on a schedule. An admin presses the button.

  • p. 37of 112

    Instructions

    Upload PDFs, save a link, or save a PDF from a web address. On a phone you can jump around the file.

  • PaidEstimated3 stale

    Collection and value

    Totals, what you paid against estimated value, values that have gone stale, and what's still sealed.

  • I bought thisOnly you see this mark

    Wishlists, with a secret

    One list per person. Anyone can privately mark "I bought this", and only they ever see it. Not admins, not the activity log. "We got it" turns a wish into a set.

  • Price Read-only

    Kid profiles

    Read-only, with no prices and no shopping list. Kids manage their own wishlist. Sets marked hidden look as if they don't exist, and the server enforces it.

  • On your diskNo CDN

    Private by construction

    Your data stays on your server. Nothing loads from a CDN, and the app makes no background downloads.

Also in the bin: CSV import from a Rebrickable set list, a Brickset export or any spreadsheet, an activity trail, a trash you can restore from, light and dark themes, and layouts made for phones first.

One page per set, one row per box

The set page shows the design once, with every copy you own listed beneath it. On a phone, the shopping list becomes a checklist you can work through in the shop aisle.

How self-hosting works

Four bricks, bottom to top

Brick Bin lives on a machine you own and answers on your own network. Most of the time goes on waiting for the catalog to download, which is a fine excuse to go and build something.

  1. Start the stack

    On a Proxmox VM or LXC with Docker, one compose file starts the app and its own Postgres 17.

  2. Reach it over Tailscale

    A Tailscale sidecar serves HTTPS at https://brick-bin.<your-tailnet>.ts.net, so the app answers only on your network.

  3. Create the household

    The first visit asks you to name the household and create the admin account. Everyone else is added from there.

  4. Import the catalog

    An admin presses the button and Brick Bin loads the LEGO catalog from Rebrickable: about 6 GB of part images plus a data archive.

Updates look after themselves. Watchtower pulls a new app image every five minutes. Postgres is never auto-updated, because databases deserve a human in the room.
