How self-hosting works

First, a home

A Proxmox VM or LXC container with Docker is the recommended home. Any machine that runs Docker will do for a try-out.

Then the stack

One compose file runs four containers: the app, its own Postgres 17, a Tailscale sidecar for HTTPS and Watchtower for updates.

Next, the address

The sidecar serves Brick Bin over HTTPS at brick-bin.<your-tailnet>.ts.net. Trying it first? Skip Tailscale and open port 3000.

Last, your household

The first visit asks you to create the household and the admin account. Then import the catalog and add a set.

What you won't find here

An account with us

You create the only account, on your own server. There is no Brick Bin cloud to sign up to.

A subscription

Brick Bin is free and open source. Nothing to renew, no tier to upgrade to.

Tracking

No analytics, nothing loaded from a CDN, no background downloads. It goes online only when someone asks it to.
