Import the LEGO catalog

Fill Brick Bin's catalog with LEGO sets and parts from Rebrickable, so you can find sets by number, pick missing pieces from a set's real inventory and see pictures of both.

What you need

  • 1×Admin account on your Brick Bin
  • 1×Computer with a browser. Copying a page's source is easier there than on a phone.
  • 6 GBFree disk, plus room for the data archive. Several GB in all.
  • 48 hSince the last import, if there was one

GoalA catalog you can search, imported by you, on your own disk.

  1. Open the catalog page

    Go to Admin → Catalog. The page says when the catalog was last imported and whether the 48-hour wait is over. On a new install it says there's nothing here yet, which is true.

  2. Copy Rebrickable's downloads page

    Open Rebrickable's downloads page in another tab. View the page source, select all of it and copy it.

    • Windows and Linux: Ctrl + U, then Ctrl + A and Ctrl + C
    • Mac: ⌥ + ⌘ + U, then ⌘ + A and ⌘ + C

    Why paste instead of fetch? Until Rebrickable confirms that automated page reads are fine, Brick Bin doesn't fetch that page itself. You copy it, the app reads the download links out of it, and everyone stays polite.

  3. Paste it into Brick Bin

    Paste into the box on the catalog page and press Check page. Brick Bin lists the files it found and their dates. If it finds none, you probably copied the page itself rather than its source; try the shortcut again.

  4. Start the import

    Press Import catalog. The first run downloads a data archive and about 6 GB of part images, so it takes a while on most connections. The page shows how far it has got.

    Nothing happens until someone presses the button. Brick Bin never imports on a schedule.

  5. Check it worked

    Open Add set and search for a set number you own. You should see it with its picture. The catalog page now shows the import time and when the next one is allowed.

About the 48-hour limit

An import can run at most once every 48 hours. Until then the button stays off and says when it will be back. So plan the big one for an evening when you won't want another tomorrow.

If Rebrickable confirms that automated reads are fine, an admin can set REBRICKABLE_PAGE_FETCH to true and skip the copy and paste.

Catalog data comes from Rebrickable.
