Hosting

The recommended home for Brick Bin: a Proxmox VM or LXC container with Docker, reached over Tailscale. Plus updates, disk space and backups.

The stack

One compose file runs four containers on a Proxmox VM or LXC container with Docker. Build it from the bottom up:

Tailscale and HTTPS

The Tailscale sidecar joins your tailnet and serves Brick Bin over HTTPS at:

Address
https://brick-bin.<your-tailnet>.ts.net

Create an auth key in the Tailscale admin console and put it in TS_AUTHKEY. Once the address works, set COOKIE_SECURE=true and restart the app.

Updates

Watchtower checks for a new Brick Bin image every five minutes and pulls it when there is one. The app runs its database migrations when it starts, unless you set AUTO_MIGRATE=false.

Postgres is never updated automatically. Database upgrades are something to do on purpose, after a backup, on a day you have time.

Disk space

Everything Brick Bin stores lives in DATA_DIR and the database volume. Plan for:

WhatHow muchBacked up?
Catalog images and dataSeveral GB, about 6 GB of it part imagesNo. Import again after a restore.
DatabaseA few hundred MBYes, without the catalog tables
Cover imagesSmallYes
Instruction PDFsTens of GB over timeYes

Backups

Back up three things, and keep a copy somewhere other than the Brick Bin host:

  • Database dumps. The catalog tables are skipped, because you can import them again.
  • Cover images from DATA_DIR.
  • Instruction PDFs from DATA_DIR.

The downloaded catalog images are not backed up. They're the biggest thing on the disk and the easiest to get back.

Example, check against your compose file
# database dump (catalog tables excluded by the backup script)
docker compose exec app ./scripts/backup-db.sh > brick-bin-$(date +%F).sql
# covers and instruction PDFs
tar czf brick-bin-files-$(date +%F).tgz data/covers data/instructions

Restoring

  1. Start a fresh stack with the same .env.
  2. Restore the database dump.
  3. Put the covers and instruction PDFs back in DATA_DIR.
  4. Run a catalog import. Your sets and missing pieces are already there; the catalog fills in their pictures and parts again.

Without Tailscale

For a try-out, run the production compose file on its own and open port 3000 (change it with APP_PORT). It serves plain HTTP, so leave COOKIE_SECURE as false and keep it on your home network.
