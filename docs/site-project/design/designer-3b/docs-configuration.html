Configuration

Brick Bin is configured with environment variables. There are fourteen. Most installs set three and leave the rest alone.

On this page
  • The ones you must set
  • Server
  • Storage and limits
  • Catalog import
  • A typical .env

Put them in the .env file beside your compose file, then restart the app. Every variable name below is a link you can share.

The ones you must set

VariablePurposeDefault
DATABASE_URLPostgres connection.Required
POSTGRES_PASSWORDDatabase password in the production compose file.Set it
TS_AUTHKEYTailscale key for the sidecar.Set it

Server

VariablePurposeDefault
APP_PORTPort published by the plain compose file.3000
COOKIE_SECURESet true once the app is served over HTTPS.false
DATA_DIRWhere covers, instruction PDFs and catalog images are kept../data
AUTO_MIGRATEfalse skips database migrations on start.true
APP_VERSIONOptional label shown in health checks and in the import's User-Agent.Empty

Storage and limits

VariablePurposeDefault
TRASH_RETENTION_DAYSDays a deleted item waits in the trash before it's deleted for good. 0 keeps it until an admin deletes it.30
INSTRUCTIONS_MAX_MBLargest PDF the app will store, in megabytes.200

Catalog import

These control where the catalog import may download from. Catalog data comes from Rebrickable, and the defaults point there.

VariablePurposeDefault
REBRICKABLE_PAGE_FETCHtrue lets the import fetch the downloads page itself. Otherwise an admin pastes the page's HTML.false
REBRICKABLE_DOWNLOADS_PAGEAddress of the downloads page.Rebrickable's page
REBRICKABLE_ALLOWED_ORIGINSOrigins the import may download from. HTTPS only.Rebrickable and its CDN
CATALOG_IMAGE_ORIGINThe only origin set covers are downloaded from.Rebrickable's CDN

Leave the page fetch off for now

Until Rebrickable confirms that automated page reads are fine, keep REBRICKABLE_PAGE_FETCH at false and paste the page. The tutorial shows how.

A typical .env

The recommended Tailscale install, with everything else left at its default.

.env
POSTGRES_PASSWORD=choose-something-long
DATABASE_URL=postgres://brickbin:choose-something-long@db:5432/brickbin
TS_AUTHKEY=tskey-auth-…
COOKIE_SECURE=true

Keep a copy of this file with your backups, and keep it out of any repository.

Variables used only by the project's tests aren't listed.
