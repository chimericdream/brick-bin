Import the LEGO catalog

Tutorial 2 of 107 stepsAdmins only

The goal

By the end, searching for a LEGO set by number or name will find it, and missing pieces will come with pictures.

The catalog is data from Rebrickable. Brick Bin never fetches it on a schedule. It arrives when an admin asks for it, and at no other time.

What you need

  • 1 ×Admin account, from the first-run tutorial
  • 1 ×Browser tab open on Rebrickable's downloads page
  • 6 GBFree disk for part images, plus room for the data archive
  • 48 hSince the last import, if there was one

Steps

  1. Open the catalog page

    Sign in as an admin and open Settings, then Catalog. If no import has run yet, the page says so and shows an empty paste box.

  2. Open Rebrickable's downloads page

    In a new tab, go to rebrickable.com/downloads/. You don't need to sign in or click anything there.

  3. Copy the page's HTML

    View the page source with Ctrl + U (⌥ ⌘ U on a Mac), select everything, and copy it.

    Why the copy and paste?

    Until Rebrickable confirms that automated page reads are fine, Brick Bin won't read that page for you. For now, you are the fetch. An admin who has permission can switch this on with REBRICKABLE_PAGE_FETCH.

  4. Paste it into Brick Bin

    Back on the Catalog page, paste into the box and press Check. Brick Bin reads the page and lists the files it will download.

  5. Press Import

    The import downloads about 6 GB of part images plus a data archive. How long that takes is up to your connection, so this is a good moment to put the kettle on.

  6. Check that it worked

    Open Add a set and search for a set number you know. If it turns up with its picture, the catalog is in.

  7. Leave it alone for 48 hours

    An import can run at most once every 48 hours. If the Import button is disabled when you come back, that is the reason, and the page tells you when it wakes up.

    Nothing updates by itself

    The catalog is only as fresh as the last time an admin pressed the button. If a brand-new set is missing from search, run another import once the 48 hours are up.

If something goes wrong

  • "No files found" after pasting. You probably copied the visible text and not the page source. Go back to step 3.
  • The import stops part-way. Check free disk space first. The part images need about 6 GB.
  • You restored from a backup and the pictures are gone. That's expected. Catalog images aren't backed up, so run an import again. See restoring.
