Know what's in every box.

Brick Bin is a free, self-hosted web app for a household's building-brick sets: LEGO, Mould King, CaDA, COBI, BlueBrixx, Lumibricks and whatever arrives next.

It runs on your own server and remembers each box you own, where it lives, how built it is and which pieces have gone missing.

What Brick Bin is, and who it's for

A set is the design and a copy is a box you own which might be sealed, half built, or four pieces short .

It's made for families and collectors who are happy running a small home server, and for anyone curious enough to start. Own five copies of the same polybag and Brick Bin keeps all five straight, each with its own build state, place, owner, price and value.

One page per set, one row per box

The set page shows the design once, with every copy you own listed beneath it. On a phone, the shopping list becomes a checklist you can work through in the shop aisle.

Shopping list

Everything missing, grouped by part and colour. Use store-trip mode on your phone, or export to BrickLink wanted-list XML, Rebrickable CSV or plain CSV.

Catalog lookup

Search LEGO sets using Rebrickable data you import yourself. Nothing is fetched on a schedule. An admin presses the button.

Instructions

Upload PDFs, save a link, or save a PDF from a web address. On a phone you can jump around the file.

Wishlists with a secret

One list per person. Anyone can privately mark "I bought this", and only they ever see the mark. Not admins, not the activity log. "We got it" turns a wish into a set.

Kid profiles

Read-only, with no prices and no shopping list. Kids manage their own wishlist. Sets marked hidden look as if they don't exist, and the server enforces it.

Collection and value

Totals, what you paid against estimated value, values that have gone stale, and what's still sealed.

Private by construction

Your data stays on your server. Nothing loads from a CDN, and the app makes no background downloads.

And the rest of the bin

CSV import from a Rebrickable set list, a Brickset export or any spreadsheet. An activity trail, a trash with restore, light and dark themes, and layouts designed for phones first.

Self-hosting, start to finish

Four bricks, bottom to top. Most of the time goes on waiting for the catalog to download, which is a fine excuse to go and build something.

  1. Start the stack

    On a Proxmox VM or LXC with Docker, one compose file starts the app and its own Postgres 17.

  2. Reach it over Tailscale

    A Tailscale sidecar serves HTTPS at https://brick-bin.<your-tailnet>.ts.net, so the app answers on your own network.

  3. Create the household

    The first visit asks you to name the household and create the admin account. Everyone else gets added from there.

  4. Import the catalog

    An admin presses the button and Brick Bin loads the LEGO catalog from Rebrickable: about 6 GB of part images plus a data archive.

Updates look after themselves. Watchtower pulls a new app image every five minutes. Postgres is never auto-updated, because databases deserve a human in the room.
