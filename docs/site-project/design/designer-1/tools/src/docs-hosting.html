Hosting

Brick Bin is built for one household on one small server. This page covers what's running, what it stores, and what to copy somewhere safe.

What runs

The recommended home is a Proxmox VM or LXC with Docker, reached over Tailscale. The compose file starts four containers.

ContainerWhat it doesUpdates
AppBrick Bin itself.Watchtower, every five minutes

Tailscale sidecarServes HTTPS at https://brick-bin.<your-tailnet>.ts.net.By you

Storage

Everything the app stores outside the database lives under DATA_DIR.

WhatWherePlan for
CatalogPart images and catalog data from Rebrickable.Several GB. The first import alone downloads about 6 GB of images.
DatabaseSets, copies, people, wishlists, the activity trail.A few hundred MB
Instruction PDFsWhatever you upload or save.Tens of GB over time
Cover imagesOne per set.Small

A single PDF can be up to 200 MB by default. Change that with INSTRUCTIONS_MAX_MB.

Backups

A backup has three parts:

  • Database dumps. The catalog tables are skipped, because they can be imported again.
  • Cover images.
  • Instruction PDFs.

Catalog images are not backed up

They're about 6 GB of files you can download again, so the backup leaves them out. After a restore, expect to run a catalog import.

Restoring

  1. Start a fresh stack, as in Setup.
  2. Restore the database dump, then put the cover images and instruction PDFs back under DATA_DIR.
  3. Sign in and run a catalog import. Your sets and copies are already there. The import brings back catalog search and the part pictures.

Running without Tailscale

The plain compose file publishes the app on port 3000. Change the port with APP_PORT. If you put your own reverse proxy in front and serve HTTPS, set COOKIE_SECURE to true.

What it downloads, and when

Brick Bin makes no background downloads, and nothing in the app loads from a CDN. It reaches out in three cases, each started by a person:

  • An admin runs a catalog import. Downloads come only from the origins in REBRICKABLE_ALLOWED_ORIGINS, over HTTPS.
  • Someone adds a catalog set, and its cover is fetched from CATALOG_IMAGE_ORIGIN.
  • Someone asks to save an instruction PDF from a web address.

Catalog data comes from Rebrickable.
